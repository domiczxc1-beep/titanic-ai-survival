# Краткая защита проекта

## Тема

**Прогнозирование выживаемости пассажира Titanic с помощью машинного обучения.**

## Что сказать преподавателю

Я создал небольшое приложение машинного обучения на основе датасета Titanic. Задача относится к бинарной классификации, потому что модель должна определить один из двух классов: пассажир выжил или не выжил.

В качестве входных параметров используются класс билета, пол, возраст, количество родственников на борту, стоимость билета и порт посадки. Перед обучением пропущенные значения обрабатываются автоматически, а категориальные признаки преобразуются методом One-Hot Encoding.

Для классификации использован алгоритм Random Forest из библиотеки scikit-learn. Датасет делится на обучающую и тестовую выборки в соотношении 80 на 20. После обучения программа рассчитывает accuracy на тестовой выборке.

Пользовательский интерфейс сделан на Streamlit. Пользователь выбирает параметры пассажира и нажимает кнопку «Сделать прогноз». После этого приложение показывает прогноз класса и вероятность выживания.

Проект хранится в GitHub-репозитории. Для запуска необходимо установить зависимости из requirements.txt и выполнить команду:

```bash
streamlit run app.py
```

## Что могут спросить

**Почему это классификация?**  
Потому что целевая переменная `Survived` имеет два класса: 0 и 1.

**Что такое Random Forest?**  
Это ансамбль решающих деревьев. Несколько деревьев делают прогноз, после чего итоговый класс определяется по их совокупному решению.

**Зачем Train/Test Split?**  
Чтобы обучать модель на одной части данных, а проверять качество на данных, которые она не видела во время обучения.

**Что такое Accuracy?**  
Доля правильных предсказаний модели на тестовой выборке.

**Что делает One-Hot Encoding?**  
Преобразует категориальные признаки, например пол или порт посадки, в числовой формат, понятный алгоритму.

**Почему есть probability?**  
Кроме конечного класса модель может оценить вероятность принадлежности пассажира к классу `Survived = 1`.
